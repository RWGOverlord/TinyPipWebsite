# Search and AI-assistant benchmark queries

The same questions, asked the same way, so we can see over time whether Google and AI assistants (ChatGPT, Gemini, Claude, Perplexity) bring up Tiny Pip for the problems it's built for, not only when someone already knows the name.

**How to run it**

- Ask each query exactly as written, in a fresh chat or a private browser window, logged out where you can.
- For AI assistants, ask with web search on if the assistant offers it.
- Record: the date, where you asked, whether Tiny Pip came up (yes/no), its position in the list if it did, and how it was described. Copy the description word for word: it shows what the assistant understood.
- Run it before the new pages are indexed (the baseline), then about every two weeks.

The goal isn't to show up everywhere at once. It's to own a few query families where Tiny Pip is an unusually good fit: starting tasks, task paralysis, gentle productivity without streaks, and a virtual pet that rewards real life.
